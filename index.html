About Me

I'm an aspiring data engineer based in Brussels — happiest when exploring datasets with Python and Jupyter, working with SQL, and building the apps and APIs that put the data to use.

I'm Microsoft Azure certified (AZ-900) and currently deepening my data engineering skills with Azure Databricks (DP-750) — I even built my own exam-prep app to study with. I can hold my own on the web side too, with Vue, Node, and C#.
